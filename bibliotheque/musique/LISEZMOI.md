# Bibliothèque musicale

Une piste par fichier, rangée par humeur : `tech/`, `positive/`, `calme/`, `energique/`.

```bash
mm musique ajouter ~/Téléchargements/piste.mp3 --humeur tech
mm musique            # liste
```

Uniquement des pistes autorisées pour un usage commercial sur les réseaux (ex. Mixkit, licence Mixkit). Les fichiers audio ne sont
pas versionnés dans Git (voir `.gitignore`). Bibliothèque vide = fond musical généré automatiquement.
