# Gabarit du guide marketing (`guide.md`)

À rédiger **seulement s'il n'existe pas** (sinon on lit celui fourni). Sources, dans l'ordre : business plan, README commercial,
site vitrine, code du projet (écrans, thème, textes de l'app), réponses d'Ok. Ce qui n'est dans aucune source reste **« À confirmer »** :
on n'invente rien. Fais valider le guide avant d'écrire le script. Il resservira pour toutes les vidéos suivantes du produit.
