# REST vs GraphQL

## LinkedIn (vidéo 4:5)
REST ou GraphQL ? Le bon choix dépend de ton projet.

REST : une adresse par ressource, et le cache HTTP natif.
GraphQL : un seul point d'entrée, et le client demande exactement les champs qu'il veut.
REST pour une API publique ou un CRUD simple ; GraphQL quand tes écrans ont besoin de données très variées.
